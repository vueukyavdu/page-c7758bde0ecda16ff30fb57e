客户端选择（本页重点）

Flyall 以通用订阅对接主流内核，不捆绑单一闭源壳。选择原则很简单：系统官方商店能上架的优先商店安装；桌面端优先可订阅、可规则分流的 Clash Meta 系；iOS 按是否已有付费客户端决定 Shadowrocket、Stash 或 Quantumult X。

  • Windows：Clash Meta / Mihomo 图形客户端，适合规则分流与系统代理。
  • macOS：ClashX Meta 或 Surge，前者贴近订阅工作流，后者适合进阶策略组。
  • Android：Clash Meta for Android 或兼容订阅的 v2rayNG，注意授权 VPN 与自启动。
  • iOS / iPadOS：Shadowrocket、Stash、Quantumult X，需自备商店账号与订阅粘贴。
  • 路由器 / OpenWrt：将订阅转为 passwall、openclash 或 homeproxy 配置，适合全家共享。

官网下载建议：仅从本页客户端说明对应的锚点进入安装指引，导入 Flyall 订阅后再测速选节点。不要在搜索引擎随意下载同名安装包。

如何快速判断该用哪一个

只看电影和网页：任意支持订阅的 Clash 客户端即可。要打低延迟游戏：旗舰版搭配可指定节点与 UDP 转发的桌面或路由器方案。公司多设备：团队版配合路由器统一出口，减少每人单独登录。

导入后请先选延迟较低的中转或 IPLC 节点做连通测试，再打开流媒体或游戏。若某个地区节点异常，切换同区域备用线路，而不是反复重装客户端。

使用场景

流媒体与内容访问

基础版覆盖常见影视站点的基础解锁；旗舰与团队强调原生解锁，减少验证码与地区不匹配。建议固定一条质量稳定的线路，避免频繁跳节点导致账号风控。

游戏与实时语音

对延迟敏感的对局，优先使用带 IPLC 说明的旗舰节点，并在客户端开启 UDP。语音软件与游戏分流到不同策略组，可降低互相抢带宽。

跨境办公与资料检索

文档协作、代码仓库与学术数据库适合长连接稳定的中转。团队版可按域名定制路由，让国内应用直连、跨境应用走订阅，减少无谓绕路。

多设备家庭共享

三到五台设备选旗舰；超过五台或需要整网覆盖，用团队版或把订阅放进路由器。手机热点共享时注意流量统计，以免提前耗尽月度额度。

操作说明

  1. 在套餐区选定基础、旗舰或团队档，完成站内订阅后复制订阅链接。
  2. 按系统进入客户端选择，安装对应程序并授予代理/VPN 权限。
  3. 在客户端粘贴订阅，更新节点列表；桌面端建议开启系统代理或 TUN。
  4. 先测延迟，再指定一条节点进行网页连通测试，确认 DNS 与规则生效。
  5. 流媒体与游戏分别建立策略组；出现缓冲或丢包时只切换节点，不改订阅地址。
  6. 流量将尽或设备超限时，升级套餐或下线闲置终端，避免连接被拒绝。

若更新订阅后节点为空，检查链接是否完整、客户端是否支持该订阅类型，并在 FAQ 中对照错误提示。

常见问题

Flyall 是机场还是 VPN？和普通加速器有何不同？

Flyall 以机场订阅方式交付节点，可在 Clash、Shadowrocket 等多客户端中使用，而不是只能打开某一个封闭 App。你得到的是可更新的节点列表与分流能力，适合同时处理网页、流媒体和游戏，而不是单一“一键加速”开关。

官方客户端应该从哪里下载？

请停留在本官网页面的客户端选择与下载锚点，按操作系统挑选 Clash Meta、ClashX、Shadowrocket 等常用工具。不要通过来路不明的网盘或同名搜索结果安装，以免订阅泄露或被植入无关模块。

订阅链接如何导入才算成功？

复制完整 HTTPS 订阅地址，在客户端选择“从 URL 更新”或“粘贴订阅”。成功后应看到分组节点而非空白。若失败，先确认套餐仍在有效期，再检查是否误开了需要额外转换的格式。

三档套餐怎么选才不浪费流量？

轻度浏览与偶尔视频用基础版；多设备、4K 与游戏选旗舰版；办公室或家庭整网、需要定制路由选团队版。年付适合已经跑通客户端、确认延迟可接受的用户。

提示设备数量超限或连接不稳定怎么办？

先在已登录设备上断开闲置会话，再重连。不稳定时更换同区域备用节点，检查本地 Wi-Fi 与系统时间。旗舰与团队含优先工单，适合需要连续在线的场景。

能否在路由器上使用 Flyall 订阅？

可以。将订阅配置到支持 Clash 或同类内核的 OpenWrt、旁路由中，即可让电视与游戏主机共享出口。团队版的高带宽与定制路由更适合这种部署。

节点与使用提醒

节点会随线路质量调整，客户端内定时更新订阅即可。本站不展示虚构评分或用户评论，请以实际延迟与解锁结果为准。合理使用流量，遵守当地与目标站点的服务条款。
